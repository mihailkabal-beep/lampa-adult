# ОПЕРАЦІЯ: ЄДИНИЙ КАНАЛ

Інтерактивний навчальний вебзастосунок для онлайн-практичного заняття з дисципліни «Основи національного спротиву».
Тема: «Індивідуальна тактика, сигнали та інформаційна взаємодія малої групи». F3 «Комп’ютерні науки», групи 31/32/41, 90 хв.

Стек: React 18 + TypeScript + Tailwind CSS + Lucide Icons + Vite. Сервер, реєстрація й платні API не потрібні.

## Швидкий старт

- **Без встановлення:** відкрийте `release/operation-yedynyi-kanal.html` (один файл, працює офлайн подвійним кліком). Його можна покласти на Google Drive / OneDrive / будь-який хостинг і дати студентам посилання.
- **Розробка:** `npm install` → `npm run dev`.
- **Збірка:** `npm run build` → `dist/` (статичний хостинг: GitHub Pages, Netlify тощо); `npm run build:single` → `dist-single/index.html`.

## Архітектура

```
src/
  lib/config.ts      модулі, тривалість, бали за кожне завдання (сума = 100), ранги
  lib/store.tsx      стан застосунку (React Context), автозбереження в localStorage, підрахунок балів
  lib/export.ts      експорт/імпорт результатів (JSON, CSV), копіювання, друк/PDF
  components/        UI-примітиви (TaskShell, Choice, OrderList…), таймер, ситуаційні картки, тости
  modules/           M1–M7, Results (підсумок), TeacherPanel (панель викладача)
```

## Обмеження (чесно)

- **Синхронізації між пристроями немає.** Кожен студент працює у своєму браузері; прогрес зберігається в localStorage.
  Робоча альтернатива серверу: студент на екрані «Підсумок» завантажує **файл результату (.json)** і надсилає в чат Teams/Meet,
  викладач імпортує файли в панелі (можна кілька одразу) → таблиця, ручні бали, рейтинг команд, частотні помилки, експорт CSV.
  Для живої спільної роботи в реальному часі потрібен сервер (напр., WebSocket / Supabase / Firebase) — його не імітовано.
- Автооцінка текстових відповідей (протокол, обґрунтування, звернення) — евристична й попередня; викладач коригує її вручну.
- Режим викладача не захищено паролем (без сервера це неможливо зробити надійно).
- PDF — через діалог друку браузера («Зберегти як PDF»), щоб коректно працювала кирилиця без сторонніх сервісів.

## Інструкція для викладача

**До заняття (5 хв):** відкрийте застосунок → «Демо-режим», пройдіть кілька завдань, натисніть «Демо-учасники» в панелі, щоб побачити таблицю. Потім вийдіть (іконка ⇥ угорі) і оберіть «Я викладач». Надішліть студентам посилання/файл.

**На занятті:**
1. Демонструйте екран. На старті попросіть студентів обрати «Я студент» і ввести ім’я, групу та **однаковий позивний для команди** (3–5 осіб; команди обговорюють рішення в кімнатах Teams/Meet, але кожен вводить відповіді у себе).
2. У панелі викладача для кожного етапу натискайте **«Запуск»** — відкриється модуль на вашому екрані й стартує таймер на його тривалість. **«■»** — завершити етап.
3. Темп: «Вільний перехід» або «Етапи відкриває викладач» (на вашому пристрої закриває наступні модулі та ситуації симуляції).
4. **Ситуаційні картки** — повноекранні слайди з таймером для обговорення (вступ, симуляція А/Б/В, фінал).
5. У симуляції — **«Показати наступну ситуацію»**, коли групи готові.
6. **«Показати правильні відповіді»** — підсвічує відповіді на вашому екрані для розбору.
7. Наприкінці студенти натискають «Файл результату (.json)» і надсилають у чат → **«Імпорт файлів»** → «Бали» для ручної корекції → рейтинг команд і «Найчастіші помилки» для фінального обговорення → «CSV» для журналу.
8. «Скинути прогрес заняття» — перед наступною групою.

Усі сценарії цивільні та навчальні; застосунок не містить бойових сигналів, тактичних команд чи процедур військового управління.
